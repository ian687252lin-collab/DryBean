## 🖥️ 第三階段：HTML 互動簡報系統沉浸式手動測試 (`midterm_slides.html`)

直接開啟：[04_期中專題_DryBean/midterm_slides.html](file:///c:/Users/IAN/Desktop/人工智慧概論/04_期中專題_DryBean/midterm_slides.html)（雙擊或以 Edge/Chrome 開啟）。

### 1. 翻頁與導航測試 (Navigation)
- [ ] **鍵盤向右鍵 (`→`) / 空白鍵 (`Space`)**：投影片順暢向後推進至 Slide 02、03。
- [ ] **鍵盤向左鍵 (`←`)**：投影片順暢向前退回。
- [ ] **`Home` 鍵**：瞬間返回第 1 頁（封面）；**`End` 鍵**：瞬間跳轉至最後一頁（第 18 頁結尾）。
- [ ] **底部導覽按鈕**：點擊「◀ 上一頁」與「下一頁 ▶」，確認當在第 1 頁時「上一頁」呈現禁用反灰狀態。
- [ ] **底部進度條**：進度條寬度隨頁數平滑增減，右下角頁碼標籤精準顯示（如 `Slide 05 / 18`）。

### 2. 快速跳轉選單測試 (Jump Select)
- [ ] 點擊頂端控制列的下拉選單。
- [ ] 任意選取 `09. 決策樹調參`，畫面是否在一秒內平滑切換至第 9 頁。
- [ ] 任意選取 `16. 攻防總結`，確認精確跳轉，且下方頁碼同步更新。

### 3. 20 分鐘計時器測試 (Countdown Timer)
- [ ] 查看右上角計時器，預設是否顯示 `20:00` 且綠點呼吸跳動。
- [ ] **按下快捷鍵 `T`**（或直接點擊計時器方塊）：計時暫停，綠點停止動畫；再次按下 `T` 恢復倒數。
- [ ] **色碼防呆**：當倒數至剩餘 5 分鐘時變為琥珀黃色警告，剩餘 2 分鐘時變為亮紅色警戒。

### 4. ⚔️ PK 攻防戰略抽屜手動測試 (對戰第 13 組利器)
- [ ] **按下快捷鍵 `P`**（或點擊頂部「⚔️ PK 攻防戰略」按鈕）：畫面右側是否順暢滑出紫色光芒抽屜。
- [ ] **分頁切換**：
  - 點擊「🛡️ 防守反擊（答辯話術）」：查看針對資料不平衡、特徵冗餘、過擬合質疑之答辯論據。
  - 點擊「⚔️ 主動進攻（質詢敵組）」：查看質詢第 13 組是否忽略標準化、有無剪枝調參之攻防題庫。
- [ ] **「📋 複製話術」功能測試**：
  - 點擊任一題目底部的「📋 複製話術」按鈕。
  - 按鈕文字應動態變為「✅ 已複製！」。
  - 開啟 Windows 記事本，按下 `Ctrl + V` 貼上，確認完整話術文本成功複製到剪貼簿。
- [ ] 再次按下 `P` 鍵或點擊抽屜右上角 `✕`，抽屜平滑向右收回。

### 5. 🎙️ 講者講稿備忘錄測試 (Speaker Notes)
- [ ] **按下快捷鍵 `N`**（或點擊「🎙️ 講者講稿」按鈕）：畫面底部是否順暢滑出深藍色備忘抽屜。
- [ ] 隨意翻動投影片（按 `→` 鍵）：底部講稿區是否即時動態連動切換至該頁的專屬逐字講稿與時間配速提醒。
- [ ] 再次按下 `N` 鍵，講稿抽屜平滑收回。

### 6. 高清圖表燈箱放大測試 (Image Lightbox)
- [ ] 翻至第 11 頁（混淆矩陣）或第 14 頁（K-Means 聚類對比）。
- [ ] **滑鼠點擊投影片上的圖表**：畫面是否暗化並彈出全螢幕高解析度燈箱大圖。
- [ ] **點擊黑色背景任一處**：大圖平滑關閉退出。

### 7. 列印與 PDF 匯出測試 (@media print)
- [ ] 在簡報網頁上按下 **`Ctrl + P`** 開啟列印對話框。
- [ ] **目標印表機**：選擇「另存為 PDF (Save as PDF)」。
- [ ] **版面配置**：選擇「橫向 (Landscape)」。
- [ ] **檢查預覽效果**：
  - [ ] 頂端導覽列、計時器、PK 按鈕已自動隱藏，不會出現在印出成品中。
  - [ ] 每一張投影片獨立佔據一整頁（分頁清楚，共 18 頁）。
  - [ ] 文字與圖表邊界無任何裁切或溢出。
- [ ] （可選）點擊儲存，即可獲得一份能離線攜帶的頂級 PDF 簡報。
